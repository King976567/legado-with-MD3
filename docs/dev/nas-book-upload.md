# 书籍详情：上传 NAS

范围：现有书籍详情菜单中的本地文件书籍。未启用首页 NAS 开关、缺地址或令牌、未通过连接验证时隐藏入口；网络连载缓存不在此入口自动导出。WebDAV 上传逻辑和书籍来源不变。

## 上传流程

1. 在应用缓存中流式生成本地文件快照，同时计算 SHA-256；最多 512 MiB，拒绝空文件。
2. 重新验证 NAS 连接、鉴权、上传能力和写权限。
3. 每页读取最多 200 条书目，用内容指纹或默认上传目录内的目标路径查重。命中后提示位置，不发送文件正文。同书名不是内容一致的证据。
4. 未命中时以 `duplicatePolicy=skip` 上传相同快照，服务端再做内容指纹/路径检查，防止并发上传覆盖已有文件。
5. 区分 uploaded、skipped、duplicates、failed；无有效结果不显示成功。正常结束、失败、取消均清理快照。

查重、上传使用同一 URL/Token 快照；设置改变或关闭入口时取消请求。弹窗支持取消，取消不会删除服务器已经接收完成的书籍。结果保存在页面对话框状态中，避免只靠瞬时 toast。

## 已知边界

- 现有 Go API 无指纹查询接口，预检需分页读取元数据；大库最多检查 500 页，未完成则停止并提示，不假定不存在。未修改后端。
- 缺少 contentHash 的旧索引项只能预检目标路径；服务端上传时仍用 skip 策略兜底。可先刷新 NAS 索引补齐指纹。
- 使用默认上传目录，不新增覆盖、保留副本或分类选择操作。
- 暂无设备连接，未做真实 NAS 写入验收。

## 回归验证

- UploadNasBookUseCaseTest：开关/验证状态、后续分页指纹命中、路径冲突、同名异版、上传参数、服务端重复竞态、只读/能力、断网、无进展分页、配置切换和异常响应。
- NasLocalBookUploadRepositoryTest：真实本地文件分块上传、指纹一致、正常/异常临时文件清理、空文件和文件名安全。
- BookInfoNasMenuTest：条件显示、独立 NAS 意图、网络书籍隐藏、只读禁用。
- NasLibraryRepositoryHttpTest：contentHash/content_hash 映射以及现有 HTTP、multipart 契约。

手动验收：启用并测试 NAS → 本地书籍详情“上传 NAS” → 首次成功 → 再次命中重复；改名相同内容仍跳过；关闭 NAS 后入口消失；只读令牌不发送正文；网络中断后可重试；WebDAV 上传保持原行为。
