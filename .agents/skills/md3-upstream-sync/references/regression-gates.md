# NAS 与漫画同步回归门槛

按本轮变更选择检查，不为无关领域发明重构。若上游更新了路径或 API，以当前代码确认入口。

## 缓存与漫画上传

- 同时检查 `BookHelp`、`ImageProvider`、漫画 page loader、缓存管理 Repository 与 NAS comic worker 的完整调用链，而非仅看能否无冲突合并。
- `.nb` 正文存在不等于漫画图片全部缓存完整。区分“目录显示缓存提示”和“完整缓存/上传缓存命中”的语义，不混用统计。
- 若改变章节子目录、图片 URL 到文件名映射或 subject 参数，测试旧书级 images、新章节目录、缓存重命名、未完整图片、解密后图片及强制刷新；上传应复用正确缓存而不是悄悄重新下载。
- 上传刷新完整目录并跳过卷标题；章节/页面进度不当作全本固定总页数。CBZ 保持章节和页面顺序、真实封面和 `ComicInfo.xml`，失败不上传半成品。
- NAS 下载保持流式临时文件、正确扩展名/类型、CBZ 本地图片书识别、精确解压、封面恢复与清理；覆盖安装时旧书仍能打开。
- WorkManager 唯一任务、后台通知、取消/重试、配置变化保护和任务历史管理保持可用；token 不持久化到任务输入或备份。

## 漫画选章与导航

- 保留明确打开请求的 request ID/章节变化语义；旧进度不得覆盖用户刚选的章节。
- 核实 Nav3 entry identity、ViewModel key、会话复用与退出保存顺序。详情完整目录选其他章节后阅读器真的到达目标，且旧 ViewModel 的退出保存不把位置写回。
- 针对跨章预取、离线开关、方向预下载、条漫 viewport 恢复、旋转和多栏导航跑行为测试。也回归普通小说目录，不能以漫画修复损坏小说。

## NAS 与设置边界

- 首页 NAS 卡片、设置页、书库入口及详情/上传/删除入口在真实导航图注册；不要丢失 Gateway/Repository/UseCase/Koin 绑定。
- 地址或 token 切换后的旧请求不能写回新连接状态；隐藏/未配置不发网络请求；只读能力不得显示可写成功。
- NAS 令牌与 WebDAV 备份配置保持分离。恢复不覆盖现有令牌，清零验证状态。不要用真实 NAS 写入/删除作为无条件自动验收。
- cache management 的 LiveData 订阅/清理仍满足主线程限制，任务历史不因合并而丢失。

## 数据库与资源

- 查实际 Room 版本、AutoMigration 和 schema；升级旧已填充数据库，确认新增字段默认值以及书籍/书架/阅读进度/朗读数据保留，不允许 destructive fallback。
- 测试不能仅把硬编码版本号替换后称已验证迁移：需要实际打开旧 schema 数据库并核对数据/默认列。
- 四套多语言资源、应用名、包名、Provider 权限保持自定义身份；新增资源引用不遗漏。
